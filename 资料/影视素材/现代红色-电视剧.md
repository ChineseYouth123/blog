# 一、1840-1917：晚清变局与辛亥革命

> 关键词：千年帝制崩塌、救亡图存、走向共和

|剧名|时间跨度|导演/主演|豆瓣评分|核心看点|
|---|---|---|---|---|
|《走向共和》|1890-1917|张黎/孙淳、马少骅|9.6|清末改革全景图，李鸿章、袁世凯、孙中山三线交织，教科书级历史剧标杆|
|《太平天国》|1843-1864|陈家林/高兰村、王诗槐|8.2|洪秀全从落第书生到天王的传奇，中国近代农民运动的悲壮史诗|
|《台湾1895》|1894-1895|韩刚/常戎、潘虹|7.5|聚焦甲午战败后台湾割让，刘永福黑旗军抗日，台湾人民不屈抗争|
|《末代皇帝》（TV版）|1908-1967|周寰/陈道明|9.3|溥仪从3岁登基到特赦出狱，一部剧读懂半部中国近代史|
|《大清盐商》|1835-1842|韩晓军/张嘉益、莫小棋|7.6|以盐政贪腐切入晚清帝国内部溃烂，政商博弈精彩纷呈|
|《一代大商孟洛川》|1858-1908|龚艺群/张桐、柏寒|7.8|山东绸商孟洛川的商战传奇，映射晚清民族工业的艰难崛起|

🔍 补充说明：

- 《走向共和》曾因"尺度大胆"被短暂禁播，后解禁重播成为神剧，大量台词至今被网友反复引用
- 如果想快速了解晚清全貌，《走向共和》+《末代皇帝》 两部足够搭建完整认知
- 📲 观看渠道：B站（部分片段）、爱奇艺、优酷（需会员）、央视网历史频道

# 二、1915-1921：新文化运动与建党前夕

> 关键词：思想启蒙、五四怒吼、开天辟地

|剧名|时间跨度|导演/主演|豆瓣评分|核心看点|
|---|---|---|---|---|
|《觉醒年代》|1915-1921|张永新/于和伟、张桐|9.3|陈独秀、李大钊、鲁迅、蔡元培群像，还原《新青年》杂志创办到中共一大的思想风暴|
|《恰同学少年》|1913-1918|龚智勇/谷智鑫、钱枫|8.9|青年毛泽东在湖南一师的求学岁月，"指点江山，激扬文字"的青春热血|
|《建党伟业》（电影）|1911-1921|韩三平、黄建新/刘烨、陈坤|7.6|明星阵容云集，快速呈现从辛亥革命到中共成立的十年|
|《我们的法兰西岁月》|1919-1927|康洪雷/朱亚文、钟秋|8.6|周恩来、邓小平、陈毅赴法勤工俭学的真实故事，弥补多数红色剧忽略的留法线|
|《问道》|1917-1921|陈力/张粟、赵樱子|7.3|以李大钊为主视角，展现马克思主义在中国早期传播的艰难过程|

🔍 补充说明：

- 《觉醒年代》是近年现象级红色剧，陈延年、陈乔年赴法留学后英勇就义的片段曾让无数观众泪崩
- 《恰同学少年》被教育部推荐为中学生必看剧目，毛泽东的"文明其精神，野蛮其体魄"名场面深入人心
- 📲 观看渠道：爱奇艺（独播）、B站（部分片段）、央视一套

# 三、1921-1927：建党初期与大革命

> 关键词：开天辟地、国共合作、北伐风云

| 剧名         | 时间跨度      | 导演/主演          | 豆瓣评分 | 核心看点                            |
| ---------- | --------- | -------------- | ---- | ------------------------------- |
| 《问苍茫》      | 1921-1927 | 王伟/王仁君、宁理      | 8.5  | 青年毛泽东从一大归来，在实践中追问"中国革命向何处去"     |
| 《光荣与梦想》    | 1921-1953 | 刘江/唐国强、侯京健     | 8.1  | 超长跨度全景剧，快速搭建1921-1953历史框架的最佳选择  |
| 《革命人永远是年轻》 | 1926-1949 | 陈健/聂远、陶飞霏      | 7.5  | 以革命爱情为主线，穿插北伐、土地革命、抗战等多个时期      |
| 《中流击水》     | 1919-1928 | 宋业明/王仁君、董勇     | 7.7  | 聚焦毛泽东、周恩来等青年革命者在大革命洪流中的成长与抉择    |
| 《大浪淘沙》     | 1921-1945 | 嘉娜·沙哈提/保剑锋、成泰燊 | 7.4  | 四个青年在革命大浪中各自抉择，展现建党初期信仰分化的残酷与坚定 |

🔍 补充说明：

- 《问苍茫》是2023年新剧，毛泽东首次在荧幕上以"34岁青年形象"登场，打破了以往特型演员的固化印象
- 《光荣与梦想》虽然跨度大导致部分情节赶进度，但胜在一部剧覆盖建党到抗美援朝，适合快速建立时间线
- 📲 观看渠道：爱奇艺、腾讯视频、优酷、芒果TV

|---|---|---|---|---|

|《红色摇篮》|1929-1934|金韬/王霙、刘劲|7.6|毛泽东、朱德在中央苏区的政权建设与反围剿斗争|
|《寻路》|1927-1932|张多福/许铂岑、罗忆楠|8.0|展现白色恐怖下，革命先辈在实践中寻找正确道路的艰辛|
|《秋收起义》|1927|张多福/侯京健、赵樱子|7.3|聚焦秋收起义全过程，文家市决策、三湾改编的历史细节|
|《绝命后卫师》（电影）|1934|董亚春/张桐、郭广平|7.2|红34师浴血掩护中央红军长征，全师几乎全军覆没的悲壮故事|
|《伟大的转折》（长征篇）|1934-1935|侯京健/侯京健、张博|7.8|聚焦遵义会议前后，毛泽东重掌军事指挥权的关键转折|

- 井冈山题材影视作品极多，如果只选一部，《井冈山》+《红色摇篮》 组合最完整

- 📲 观看渠道：央视一套（多数首播）、爱奇艺、优酷、腾讯视频

|---|---|---|---|---|

|《伟大的转折》|1934-1935|侯京健/侯京健、张博|7.8|聚焦遵义会议到会理会议，展现毛泽东如何在党内斗争中确立领导地位|
|《长征大会师》|1936|万盛华/佟瑞欣、刘劲|7.5|重点讲述三大主力会师后的西路军西征与西路军的悲壮结局|
|《草地》（电影）|1935|汪涛/李卓、马境|7.0|以红军过草地为核心，还原极端环境下的人性考验与信仰力量|

# 六、1935-1945：延安时期与抗日战争

> 关键词：延安岁月、全民抗战、中流砥柱

|剧名|时间跨度|导演/主演|豆瓣评分|核心看点|
|---|---|---|---|---|
|《延安颂》|1936-1945|宋业明/唐国强、刘劲|8.3|党中央进驻陕北到七大召开，完整展现延安十年的光辉历程|
|《东方战场》|1931-1945|路奇/黄海冰、罗嘉良|7.4|全球视角全景抗战，首次大量呈现苏联援华、太平洋战场等国际维度|
|《我们的河山》|1937-1945|毛卫宁/王雷、陈钰琪|待定|2025年央视热播，聚焦山东沂蒙抗日根据地，单日收视率3.616%创新高|
|《太行山上》|1937-1940|李伟/张再新、杨骏|7.9|聚焦八路军在太行山的敌后抗战，朱德、彭德怀、左权的指挥艺术|
|《百团大战》（电影）|1940|宁海强/陶泽如、刘之冰|6.5|还原1940年百团大战的激烈战况，战争场面宏大|
|《我的团长我的团》|1942-1945|康洪雷/段奕宏、张译|9.5|中国抗战剧天花板，滇西远征军的残酷与荒诞，人性深度远超同类题材|
|《亮剑》|1940-1955|陈健/李幼斌、何政军|9.5|李云龙式的草根英雄，抗日+解放+建国三段式，国民级红色剧王|
|《中国远征军》|1942-1945|董亚春/黄志忠、柯蓝|8.5|首部聚焦中国远征军入缅作战的电视剧，填补了这段历史的影视空白|
|《战争与人》（电影）|1931-1946|王冀邢/吴京安、张玉洁|7.3|以知识分子视角串联抗战全过程，思想深度突出|

🔍 补充说明：

- 《我的团长我的团》豆瓣9.5，被誉为"中国战争剧的巅峰"，台词字字如刀，看完会对战争有全新认知
- 《亮剑》虽然豆瓣9.5，但严格来说它跨越了抗战+解放+建国，按时间线应拆到后面再看
- 抗战剧如果只看三部，推荐 《我的团长我的团》+《亮剑》+《太行山上》
- 📲 观看渠道：B站（我的团长我的团）、爱奇艺（亮剑独播）、央视网、腾讯视频

# 八、1949-1957：新中国成立初期

|剧名|时间跨度|导演/主演|豆瓣评分|核心看点|
|---|---|---|---|---|
|《跨过鸭绿江》|1950-1953|董亚春/丁勇岱、孙维民|8.7|最权威的抗美援朝电视剧，彭德怀挂帅出征，上甘岭战役等名场面还原到位|
|《东方》|1949-1957|路奇/唐国强、孙维民|8.0|全方位展现新中国成立初期的政权建设、经济恢复、外交突破|
|《特赦1959》|1949-1959|董亚春/张铎、奚望|8.4|（同上表，跨两个时期）战犯改造的人文视角，温情与深度并存|
|《海棠依旧》|1949-1976|陈力/孙维民、唐国强|7.8|以周恩来为主视角，串联新中国外交与内政的重大事件|
|《五星红旗迎风飘扬》|1950-1984|王晓明/唐国强、陈建斌|7.3|跨越三十年的宏大叙事，"两弹一星"科学家群像是核心亮点|
|《绝密543》|1958-1967|宋海波/王聪、陈维涵|7.7|聚焦地空导弹部队组建，还原击落U-2侦察机的真实事件，年轻观众也爱看|

- 《跨过鸭绿江》首次在电视剧中完整呈现抗美援朝全过程，很多细节是电影《长津湖》没拍到的
- 如果对"两弹一星"感兴趣，《五星红旗迎风飘扬》+ 《功勋》（2021单元剧，豆瓣9.0） 必看
- 📲 观看渠道：央视一套、爱奇艺、优酷、芒果TV

|剧名|时间跨度|导演/主演|豆瓣评分|核心看点|
|---|---|---|---|---|

|《历史转折中的邓小平》|1976-1984|吴子牛/马少骅、萨日娜|8.3|聚焦十一届三中全会前后，邓小平如何力排众议开启改革开放|
|《人间正道是沧桑》|1925-1949|张黎/孙红雷、黄志忠|8.6|虽主要讲国共斗争，但延伸到建国前夕，情感深度远超一般红色剧|

|《山海情》|1991-2016|孔笙/黄轩、张嘉益|9.2|虽始于90年代，但从宁夏西海固搬迁写起，是理解中国扶贫与发展的必看神剧|

|《人世间》|1969-2016|李路/雷佳音、辛柏青|8.1|虽非纯红色剧，但以周家三代人串联中国社会变迁，是近年最有分量的年代剧|
|《我们的四十年》|1978-2018|王梓/金世佳、柴碧云|7.2|聚焦电视行业四十年变迁，以小见大反映改革开放成就|

🔍 补充说明：

- 《功勋》是近年红色剧中口碑最好的，8个单元每单元6集，质量稳定，适合碎片时间观看
- 《大江大河》+《山海情》虽然起点较晚，但承接改革开放叙事，强烈推荐连着看
- 📲 观看渠道：爱奇艺（功勋）、优酷（山海情）、腾讯视频（大江大河）、芒果TV（人世间）
