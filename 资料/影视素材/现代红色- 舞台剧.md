# 七、创作趋势洞察（2025-2026）

1. "小切口"取代"大叙事"：如《铁流东进》用小人物成长替代宏大战争，《家书里的中国梦》用三代家书串联百年
2. 技术赋能舞台：全机械转台、动态投影、LED流动画卷、蒙太奇多媒体成为标配
3. 戏曲+红色跨界：琼剧《百年红宅》、京剧《北国红菇娘》让非遗与红色题材融合
4. 巡演常态化：《觉醒年代》2026年已从上海巡至南通、江苏、闽南，红色剧目市场化运营加速
5. 基层创作活跃：贵港市红色舞台剧大赛涌现《桂·光》《文秀日记》等贴近地域特色的作品
