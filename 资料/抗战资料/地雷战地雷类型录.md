# 电影《地雷战》地雷类型录

> 抗日战争时期（1937-1945），敌后抗日根据地军民在极端艰苦的条件下，因地制宜、就地取材，创造出数十种土制地雷，形成了独具特色的地雷战法。以下按材料、引爆方式、战术用途等维度，系统梳理地雷战中的主要地雷类型。

---

## 一、按制造材料分类

### （一）铁雷

由兵工厂统一铸造的制式地雷，外壳为生铁，威力较大，但数量有限。多由上级配发给主力部队或重点村庄。铁雷外壳爆炸后形成大量破片，杀伤力强。

### （二）石雷

就地取材，以山中青石、花岗石凿制而成，是地雷战中用量最大、最具代表性的地雷类型。

| 项目 | 说明 |
| --- | --- |
| 原材料 | 山中青石或花岗岩 |
| 制法 | 将石头凿成圆球或方块，中间钻直径约3-4厘米的装药孔，填入自制炸药（一硝二磺三木炭），插上起爆管，黄泥封口 |
| 优点 | 原料取之不尽，造价极低，探雷器无法探测 |
| 推广顺口溜 | "一块青石蛋，当中凿个眼；装上四两药，安上爆发管；黄土封好口，弦子拉外边；鬼子来扫荡，石雷到处响" |

石雷在山东海阳地区使用最为广泛，当地民兵先后制造了数万枚石雷。

### （三）陶雷/瓷雷

利用陶罐、瓷坛等容器装填炸药制成。外壳坚硬，破裂后形成锐利碎片，且不具金属性质，可有效规避探雷器。

### （四）木雷

以木箱或挖空的树干为壳体，内装炸药和铁钉、碎铁片等填充物。制作简单，但威力相对较小，多用于骚扰和牵制。

## 二、按引爆方式分类

### （一）踏（压）发雷

| 特性 | 说明 |
| --- | --- |
| 引爆方式 | 人踩踏或车辆碾压后触发，利用压力使击针撞击火帽引爆 |
| 适用场景 | 道路、山口、桥头等敌人必经之地 |
| 战法 | 常布设于公路、田埂、巷口，日军人马踩踏即炸 |

### （二）绊发雷

| 特性 | 说明 |
| --- | --- |
| 引爆方式 | 拉线横拉于路面或草丛中，触碰拉线后拽动保险销引爆 |
| 适用场景 | 小路、树林、庄稼地等隐蔽路径 |
| 特点 | 可在较远距离外由埋伏民兵控制时机 |

### （三）拉发雷

由埋伏在暗处的民兵观察敌情，待敌进入雷区后手动拉动绳索引爆。优点在于"不见鬼子不挂弦"，可精准选择引爆时机，避免误伤群众或牲畜。

### （四）定时/缓燃雷

安装延时引爆装置，常用于埋设在敌军据点附近或交通要道。民兵撤离现场后按设定时间自动爆炸，制造恐慌并切断敌军退路。

### （五）化学（动发）雷

| 特性 | 说明 |
| --- | --- |
| 结构 | 雷体内置敞口硫酸瓶，瓶口以金属片或蜡纸密封 |
| 原理 | 稍有翻转倾斜，硫酸流出与炸药中的氯酸钾接触，发生剧烈化学反应引燃炸药 |
| 特点 | 延时爆炸，敌军挖出后搬运或拆卸时因倾斜晃动而引爆 |
| 电影情节 | 敌工兵渡边偷雷回据点研究，拆卸时雷体翻转引爆，渡边被炸死 |

此雷又称"扳不倒"，专用于反工兵排雷。

### （六）头发丝雷

| 特性 | 说明 |
| --- | --- |
| 结构 | 以头发丝替代麻绳作绊线，连接一根伸缩力大的橡皮条 |
| 灵敏度 | 极为灵敏，发丝轻微受力即触发 |
| 战术价值 | 日军工兵用放大镜沿地面搜索绳索引线，但头发丝极细、色黑，难以被发现 |
| 效果 | 有效克制了日军的排雷手段 |

## 三、按战术组合分类

### （一）子母雷

| 特性 | 说明 |
| --- | --- |
| 结构 | 地雷（母雷）在上，其下放置数枚手榴弹或小型地雷（子雷） |
| 引爆后效果 | 母雷先炸，将子雷抛向空中，子雷在空中或落地后二次爆炸 |
| 杀伤特点 | 范围大，可有效杀伤骑兵、行军大队 |
| 战法 | 埋设于开阔地带，专炸敌行军纵队 |

### （二）连环雷

| 特性 | 说明 |
| --- | --- |
| 结构 | 用铁丝或绳索将数枚地雷串联 |
| 引爆后效果 | 踩响其中一枚，连带引爆全部串联地雷 |
| 杀伤特点 | 爆炸覆盖面积广，威力叠加，可一次杀伤大量敌人 |
| 战法 | 布设于主通道、桥梁、隘口，封堵敌军行进路线 |

### （三）真假雷

| 特性 | 说明 |
| --- | --- |
| 结构 | 假雷（空壳或无药）在上、真雷在下，假雷与真雷的引信相连 |
| 战术意图 | 敌人发现假雷后放松警惕，搬运假雷时牵动真雷引爆 |
| 效果 | 专门针对日军工兵排雷，使其防不胜防 |

### （四）碎石雷（天女散花）

| 特性 | 说明 |
| --- | --- |
| 结构 | 在簸箕形石坑或断崖上放置炸药，盖木板，堆碎石块 |
| 引爆后效果 | 炸药爆炸将大量碎石抛向四面八方，如天女散花 |
| 杀伤特点 | 覆盖面积大，碎石如弹片般散射，对无防护人员杀伤力极强 |
| 战法 | 封锁路口、山口、海滩、河道等险要地形 |

电影中赵虎将其命名为"天女散花"，是最具观赏性的地雷战法之一。

### （五）长藤雷

| 特性 | 说明 |
| --- | --- |
| 背景 | 日军强抓百姓走在前面蹚雷开路 |
| 结构 | 地雷引线接长绳，由远处民兵掌控 |
| 战法 | 百姓通过后、日军踩上雷区前，民兵迅速拉发引爆 |
| 效果 | 保护群众安全，专炸后续敌军 |

### （六）空中绊雷（天雷）

| 特性 | 说明 |
| --- | --- |
| 结构 | 将地雷悬挂于树梢或房梁，绊线与地面相连 |
| 引爆后效果 | 地雷在齐胸或头部高度爆炸 |
| 杀伤特点 | 专打敌指挥官、骑兵，伤害要害部位（头、胸） |

### （七）水雷

| 特性 | 说明 |
| --- | --- |
| 结构 | 以防水材料（蜡、油布）密封的地雷，浮于水面或置于浅水中 |
| 适用场景 | 河流渡口、水田、水塘 |
| 效果 | 日军改走水路避雷时，遭水雷打击 |
| 传说 | 电影中民兵将水雷布设于河中，炸得日军船只人仰马翻 |

## 四、特种/趣味地雷

### （一）蝎子雷

在铁夹上安装地雷，既能当踏雷使用，又能当绊雷使用，形似蝎子，故得名。一雷多用，灵活布设。

### （二）钉子雷

地雷外壳外加装大量铁钉、碎铁片，爆炸时铁钉四射，增大杀伤半径和穿透力。

### （三）仙人脱衣雷

地雷有内外两层壳体，外层导火管不起作用。日军挖出后拆解外层时，触动内层引信即爆炸。专用于诱杀排雷工兵。

### （四）前踏后发雷（缓燃起爆雷）

| 特性 | 说明 |
| --- | --- |
| 结构 | 触发装置在前、地雷在后，中间以缓燃导火索连接 |
| 效果 | 前列群众踩过触发装置，地雷在数秒后才爆炸 |
| 战术价值 | 群众安然通过，后续日军被炸 |

### （五）臭雷（恶作剧雷）

以粪便或恶臭物装填伪装的假地雷，日军挖出后发现被戏弄，用以打击敌军士气。多见于电影中的儿童团员布设。

## 五、地雷数量与战果

根据地雷战纪念馆资料，海阳民兵先后发明了**36种**地雷，包括但不限于以上各类。抗战期间，仅山东海阳地区，民兵利用地雷作战**2000余次**，毙伤俘敌**1800余人**，有力地打击了日本侵略者。

---

## 六、地雷战的核心原则

> **"不见鬼子不挂弦"**

地雷战的精髓不在于地雷本身的威力，而在于**人民的智慧**：
- 就地取材、自力更生（无铁造石雷，无火药自己碾）
- 虚虚实实、真真假假（真假雷、伪装雷）
- 灵活机动、因地制宜（根据地形、敌情选择雷种和战法）
- 发动群众、全民参与（村村布雷、户户有雷）

正如毛泽东所言：**"战争的伟力之最深厚的根源，存在于民众之中。"**
